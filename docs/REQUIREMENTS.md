# PichiaCLM 需求

## 定位

PichiaCLM 是面向毕赤酵母表达设计的 CDS 候选生成与序列审查工具：它把氨基酸序列转换为同义 CDS 候选，并为生成或外部 CDS 提供可复核的质量信息。

它不是蛋白设计工具，也不预测表达产量、分泌效率或湿实验结果。

## 能力边界

工具应能：

- 生成单条或批量氨基酸输入的 CDS，并提供多个可比较候选；
- 对 CDS 检查翻译一致性、GC、密码子使用、序列重复、同聚碱基、motif 和限制性内切酶位点；
- 将候选的质量状态、CAI（训练数据和公开 Kazusa 参考）及密码子偏好统计作为审查信息输出；
- 通过 CLI、HTTP API 和本地 Streamlit 界面提供相同核心能力；
- 导出供后续人工审查的 FASTA、CSV 或 JSON 结果。

工具不得将预测、CAI 或质量检查结果表述为实验成功、最终构建设计或订购 DNA 的充分依据。

## 验收

一个能力切片只有在以下层次均成立时才可验收：

1. 核心层对有效与无效输入给出稳定、可测试的结果；
2. 对外接口正确传递核心层的输入、结果与错误；
3. 面向用户的结果保留审查所需的限制和风险信息。

成功意味着候选 CDS 及其审查信息可被可靠生成和复核；不以新增页面、字段或模型分数作为成功定义。
